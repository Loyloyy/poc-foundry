# PoC Chatbot

A small, runnable Gradio chatbot generated by **poc-foundry** (Stage 3) from a Stage-2 research
artifact. It is intentionally minimal and verifiable.

- `core.py` — the pure logic (`generate_reply`); unit-tested, no UI, no network at import.
- `app.py` — a thin `gr.ChatInterface` over `core.generate_reply`.
- `tests/` — the suite that gates the build (and the clean-room re-run).
- `RUN.md` — copy-paste blocks to install, test, and launch.

See `RUN.md` to run it. See `AGENTS.md` if you want to continue building on it (e.g. in OpenCode).
